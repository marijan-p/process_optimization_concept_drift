\section{Concept Drift an der Anlage} \label{sec:mill_drift}
%---------------------------------------------------------------
% Gegenstueck zu sec:syn_drift / sec:tep_drift. Dort wird der Drift konstruiert, hier wird
% beschrieben, woher er kommen kann und was davon messbar ist.
%
% [D1] Driftquellen -- Verschleiss (Walzenmaentel, Mahlteller), Wartung (Mantelwechsel,
%      Aufschweissen), Kalibrierung des Walzen-Offsets, Materialeigenschaften (Feuchte,
%      Zusammensetzung), Fahrweise der Operatoren, aeussere Bedingungen.
%      Quelle: Expose Abschnitt 5.2 (Liste der aeusseren Einfluesse), MA Igel 2024 Kap. 4.2.
%
% [D2] Was davon gemessen ist -- Walzenhoehen (A56-HS01.ZZ01..04), Kalibriersignal als
%      protokollierte Nullsetzung (A56-HS01.ZO01..04), Materialfeuchte (A53-2N01.QZ01),
%      Wassereindüsung (A56-WI01.FC01), Durchsatzzaehler. Nicht gemessen: Zusammensetzung
%      des Materials, Mahlfeinheit. Keine Tag-Namen im Text, nur in einer Fussnote oder im
%      Anhang.
%
% [D3] Was eine Kalibrierung ist -- Offset wird genullt, wenn die Walzen auf dem Teller
%      liegen: nach jeder Wartung, aber auch beim Ausraeumen einer vollgelaufenen Muehle oder
%      versehentlich. Kalibrierung markiert damit einen Eingriff, nicht zwingend eine Wartung.
%
% [D4] Einordnung nach Tabelle~\ref{tab:cd_definitionen} -- Verschleiss aendert bei gleichen
%      Stellgroessen die Zielgroesse, erwartet wird Real Concept Drift. Die Fahrweise
%      verschiebt die Eingangsverteilung (Covariate Shift). Unterschied zu Kap. 3: Ursache
%      und Verlauf des Drifts sind nicht bekannt, nur indirekt beobachtbar.
%
% [D5] Abgrenzung Messkette -- Die Umbauten am Sichter (09/2024) und am Hauptantrieb
%      (05/2025) aendern die Messkette, nicht den Prozess im Sinne eines Drifts. Sie begrenzen
%      den Betrachtungszeitraum. Kann alternativ in sec:mill_data stehen.
%      Quelle: _shelf/mill (Mission Report, Site Report KW19/2025), wissen/muehlendaten.
%
%---------------------------------------------------------------
